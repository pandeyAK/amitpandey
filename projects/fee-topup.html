The Challenge

A 20-minute detour at the worst possible moment

Qredo charges transaction fees denominated in QRDO, the platform's native utility token. Users who run out of QRDO must exit the Qredo platform entirely, navigate to a centralized exchange, purchase QRDO, transfer it to their Qredo wallet, and return — a process that takes 20+ minutes and creates a meaningful drop-off point at exactly the moment a user is trying to transact.

The Solution

Fiat-to-QRDO, without leaving the app

I reduced friction in QRDO acquisition by enabling existing Qredo users to purchase QRDO tokens directly within the Qredo web application using fiat currency, via an integrated Banxa-hosted checkout.

  • Fiat-to-QRDO on-ramp only (no off-ramp)
  • Layer 1 (L1) Qredo wallets only (L2 wallets deferred)
  • Web application only (mobile deferred)
  • Banxa hosted checkout via API redirect integration
  • QRDO as default pre-selected token in Banxa checkout
  • Top-up entry point in: (a) fee collection section, (b) user profile section
  • Webhook-based order status monitoring from Banxa
The Impact

$50K+ collected, and a foundation for what came next

I collected over 50,000 in fees in the first month, expanded QRDO token access to multiple countries, and increased QRDO staking. I paved the way for new products like staking and the Exchange Hub, and received highly positive customer feedback.

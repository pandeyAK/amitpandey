The Challenge

2-3 days of hand-holding through vague NixOS errors

Holo's original model required a physical device, the Holoport, running NixOS, with no terminal or keyboard, to host Holochain applications. In practice, this meant 2-3 days on average to successfully deploy a Holochain application, almost entirely spent on back-and-forth hand-holding through vague NixOS errors.

The Solution

Any device, zero setup friction

Any device, laptop, phone, or a $5 VPS, ran Holochain applications with zero setup friction, contributing spare compute back to the network. I drove user research, wrote the PRD, and led the combined engineering, UX, and QA squad through delivery. I ran Agile ceremonies, owned the backlog, and coordinated directly with external Holochain application developers who needed to prototype against the new architecture. I personally tested every release before it shipped and ran internal demos that proved the core claim: deployment time was now down to one CLI command.

The Impact

38,600 container pulls and a durable model

The EdgeNode image achieved 38,600 total container pulls. I reduced deployment time from 2-3 days to a single CLI command. The project remains active, and my ongoing contributions show the model's durability beyond the initial launch.
